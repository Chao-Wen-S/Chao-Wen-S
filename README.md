## 现在 / Now

- **在读** — 基础课和论文，先把底层补扎实。
- **在写** — 小工具、小实验；能跑起来，才算数。
- **在记** — 学过的东西写下来，防止自己骗自己。

## 三条原则 / Three rules

1. **先跑通，再优化。** Make it work, then make it fast.
2. **写下来才算学会。** If I can't explain it, I don't know it.
3. **不做没必要的抽象。** No abstraction before the third repetition.
